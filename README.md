# Python Scripting

Learning Python for automation, system scripting,
and DevOps tooling.

## Topics
- Basics — variables, loops, functions, programs
- File operations — read, write, CSV, JSON
- OS and system — env vars, disk, shell commands
- Automation — file organizer, backup scripts
- Networking — HTTP requests, port scanner
- Log parsing — filter, summarize, analyze

## Goal
Build scripting skills for MLH Production Engineering
and DevOps workflows efficiently.
